# KPI GLINT Pipeline

This project builds a KPI panel, ranks weak pillars, and then discovers a causal graph from the selected KPI set.

## Setup

Install the dependencies first:

```bash
pip install -r requirements.txt
```

## 1) Run weakest pillar

General format:

```bash
python3 weakest_pillar.py <dataset_dir> <output_dir> [--artifacts-path <artifacts_dir>] [--recommend-list <recommendation_file>] [--profile]
```

Example:

```bash
python3 weakest_pillar.py ./dataset ./output/weakest_pillar
```

Optional profiling:

```bash
python3 weakest_pillar.py ./dataset ./output/weakest_pillar --profile
```

This writes the KPI panel and related metadata into the target output folder.

> Recommended KPI recommendation JSON-LD files are already present under the dataset's causal folder, such as `dataset/causal/*.json` or `dataset/causal/*.jsonld`. You can point `--recommend-list` at one of these files to choose a recommended KPI set for the run.

## 2) Run causal graph

General format:

```bash
python3 causal_graph.py <weakest_pillar_output_dir> <causal_output_dir> [--artifacts-path <artifacts_dir>] [--n-jobs <n>] [--no-gcm] [--profile]
```

For a lightweight run without the DoWhy/GCM refinement step and without profiling:

```bash
python3 causal_graph.py ./output/weakest_pillar ./output/causal_graph --no-gcm
```

If you want profiling enabled:

```bash
python3 causal_graph.py ./output/weakest_pillar ./output/causal_graph --profile
```

If you want the full GCM-based refinement enabled instead of skipping it:

```bash
python3 causal_graph.py ./output/weakest_pillar ./output/causal_graph
```

## Notes

- `weakest_pillar.py` expects the dataset folder to contain the KPI metadata and CSV files.
- `causal_graph.py` expects the output directory generated by `weakest_pillar.py`.
- `--no-gcm` skips the DoWhy-based GCM refinement and keeps the run lighter.
- `--profile` is optional and writes timing metadata into the artifacts folder.
